# SkyboundSlayer

C++ / DxLib / Effekseer を使用して制作した3Dアクションゲームです。

---

## 📋 作品概要

* **タイトル**: SkyboundSlayer
* **ジャンル**: 3Dアクションゲーム
* **制作人数**: 1人（個人制作）
* **制作期間**: 約2ヶ月
* **担当箇所**: 企画、設計、C++プログラミング、エフェクト組み込み、UI実装全般
* **使用言語・ライブラリ**: 
  * C++ (C++17)
  * DxLib
  * Effekseer (EffekseerForDXLib)
  * Visual Studio 2022

---

## 🕹️ ゲームの特徴とシステム

* **3Dウェーブ制アクション＆ショップシステム**:
  * 敵を撃破してゴールドを獲得し、ウェーブ間の強化ショップでステータス（HP・攻撃力・移動速度等）を自由にいじるビルド構築。
* **高精度なヒット判定とフィードバック**:
  * スイープ判定 / ベクトル補正による高速移動時のすり抜け防止。
  * 物理ノックバック、ダメージUIポップアップ、ヒットストップ、カメラシェイクによる爽快な打撃感。

---

## 🛠️ プログラム設計・アーキテクチャのアピールポイント

### 1. コンポーネント指向の疎結合設計
* **コライダーのコンポーネント化**:
  * 単一の巨大なクラスを作らず、`SphereCollider` や `CapsuleCollider` を独立したコンポーネントとして所有・アタッチする設計。
  * コライダー側で親アクターの行列・位置と同期し、イベント駆動（`OnEnter`, `OnTrigger`, `OnExit`）で安全に処理を分離。

### 2. 階層化された State パターン（有限状態マシン）
* **破綻のない状態管理**:
  * ゲーム全体進行（`Phase`）、敵AI・ボスの大技（`AttackState`）、アニメーション（`AnimationState`）、ショップ演出（`ShopState`）を状態定義し、IF文の乱立やバッティングバグを未然に防止。

### 3. サービスロケーターパターン (`Master` クラス)
* **依存関係の整理**:
  * 各マネージャー（`SoundManager`, `SceneManager`, `Camera` 等）へのアクセスを統一窓口でカプセル化し、引数のバケツリレーを解消。

### 4. オブジェクトプール & 二段階安全破棄（Deferred Deletion）
* **パフォーマンスと安全性の確保**:
  * `EffectPool` によるメモリ割り当てオーバーヘッドの抑制。
  * 更新・描画ループ中での不正アクセス（ダングリングポインタ）を防ぐ `delete_flag_` による安全な遅延解放フレームワーク。

## 🎮 操作方法

* **[ W ][ A ][ S ][ D ]**: 移動
* **[ SPACE ]**: ジャンプ / 空中回避
* **[ 左クリック ]**: 通常攻撃
* **[ 右クリック ]**: スライド攻撃 / スキル
* **[ E ]**: 攻撃モード切り替え
* **[ R ]**: アイテム使用
* **[ Enter ]**: ショップ会話・購入
* **[ BackSpace ]**: ショップを閉じる
* **[ ESC ]**: ゲーム終了確認（誤終了防止機能付き）
