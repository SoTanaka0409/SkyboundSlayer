# Skybound Slayer
「回避からの一撃！爽快アクション × 自由なキャラビルド」
本作は、C++とDxLibを用いて基盤から独自実装した3DアクションRPGです。
## 概要
- **ジャンル**：3DアクションRPG
- **プラットフォーム**：PC (Windows)
- **開発環境 / 言語**：C++ / DxLib / Effekseer
- **開発規模**：個人制作
## 技術的なアピールポイント 
既存のエンジン（UnityやUnreal Engineなど）に頼らず、アクションゲームの根幹である「気持ちいい手触り」をゼロから実装した技術力が最大の強みです。
* **独自の当たり判定システムのフルスクラッチ開発**
  * 既存の物理エンジン等を使用せず、3D空間におけるプレイヤーと敵・攻撃判定のコリジョン処理を独自に計算・実装しました。
* **アニメーションと同期した状態遷移（ステート）管理**
  * コンボ攻撃、ジャンプ攻撃、スライドアタック、無敵時間を活用した回避など、多彩なアクションをステートパターンを用いて管理。アニメーションの再生フレームと厳密に同期させることで、レスポンスの良い爽快なアクションを実現しています。
* **拡張性の高いキャラビルド（ショップ）システム**
  * 「最大HP」「攻撃力」「移動速度」「回避性能」などのパラメータを動的に管理・強化できる基盤を設計・実装しました。
* **EffekseerによるリッチなVFX制御**
  * EffekseerのデータをC++コード上で制御し、ボスの広範囲魔法攻撃などのエフェクトをバトルの進行に合わせて動的に発生させています。
## 主な機能・ゲームサイクル
1. **探索・戦闘**：3Dステージを進行し、多彩なアクションで通常エネミーを撃破。
2. **報酬・強化**：獲得した資金を使ってショップでステータスを強化。
3. **ボス討伐**：強化したキャラとプレイヤースキルを駆使して、複数の攻撃パターンを持つボスに挑む。
